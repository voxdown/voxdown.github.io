# voxdown.github.io

This repository serves the address `voxdown.github.io`. It only sends visitors on to the playground at `voxdown.github.io/voxdown/`, which is built and deployed from [voxdown/voxdown](https://github.com/voxdown/voxdown). Any other address is kept, so `voxdown.github.io/spec.html` arrives at the spec.

If the project gets its own domain, it is set here, under Settings → Pages. GitHub then serves the playground at that domain's `/voxdown/` too.
